# Episode 001 — System map

Published video: https://www.youtube.com/watch?v=YRGF0TWYnFo

Episode 001 defines the project boundary rather than one executable experiment.

The core idea is:

```text
data
  ↓
research / target / features
  ↓
models
  ↓
evaluation
  ↓
risk / execution
  ↓
monitoring
```

A model is only one component of a trading system.
